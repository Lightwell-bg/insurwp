# InsurWP Mini App — калькулятор страховки в Telegram

Telegram Mini App для https://miniapp.bginfo.eu/: та же форма расчёта, что и на сайте,
но с нативным для Telegram интерфейсом.

Расчёт здесь не дублируется. Приложение — тонкий клиент REST API плагина InsurWP:
формулы, тарифы и сборка ссылки на оформление остаются в WordPress.

## Стек

React 19 + TypeScript + Vite. Роутера нет — приложение одноэкранное.
SDK Telegram подключается скриптом в `index.html`, пакета в npm для него не существует,
поэтому типы описаны в `src/types/telegram.d.ts`.

## Оформление

Своя фирменная палитра поверх темы Telegram — токены `--brand-*` в `src/styles/theme.css`
и `src/lib/brand.ts` (те же значения нужны и в JS: нативная кнопка Telegram красится
через `MainButton.setParams`, CSS-переменную туда не передать). `--tg-theme-*`
по-прежнему определяет фон/текст/бордеры и переключает светлую/тёмную тему — акцент
намеренно свой, не зависит от того, какой блёклый цвет достался пользователю в Telegram.

Под калькулятором — блок «Что дальше» (`src/components/Services.tsx`,
`src/data/services.ts`): аккордеон ссылок на платные услуги bginfo.eu (ВНЖ,
гражданство, бизнес) и карточка-CTA на цены и заявку. Список ссылок правится
только в `services.ts`, вёрстки не касается.

## Как это работает

1. При старте запрашивает `GET /wp-json/insurwp/v1/options` — сроки, лимит, территории
   и границы дат. Справочники приходят с сервера, чтобы приложение не разъехалось
   с тарифами, которые администратор правит в админке WordPress.
2. По нажатию главной кнопки шлёт `POST /wp-json/insurwp/v1/quote` и показывает
   предложения, отсортированные по цене.
3. Кнопка «Заказать» открывает страницу оформления через `openLink` с выключенным
   Instant View — иначе скрипт на той странице не выполнится и поля останутся пустыми.

Запросы идут без cookie и без `X-WP-Nonce`: маршруты публичные, а nonce WordPress
с чужого домена всё равно не получить. Домен приложения должен быть разрешён в админке:
«Страховка → Настройки → Адреса мини-аппа».

## Переменные окружения

Файл `.env` (шаблон — `.env.example`):

| Переменная | Назначение |
|---|---|
| `VITE_INSURWP_API_BASE` | Базовый адрес API. В разработке `/api` — запрос идёт через прокси Vite и не упирается в CORS. На проде `https://bginfo.eu/wp-json/insurwp/v1`. |
| `VITE_INSURWP_API_PROXY` | Куда прокси Vite шлёт `/api` в разработке. По умолчанию `https://bginfo.eu`; укажите свой адрес, чтобы работать против локального WordPress. |

## Команды

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm test         # юнит-тесты (vitest)
npm run build    # проверка типов и сборка в dist/
```

Вне Telegram приложение работает как обычная страница: вместо нативных кнопок
Telegram показываются обычные, тема берётся из настроек системы. Это штатный режим
для разработки.

## Проверка внутри Telegram

Mini App обязан открываться по HTTPS, поэтому локальный дев-сервер нужно выставить
наружу туннелем:

```bash
npm run dev -- --host
cloudflared tunnel --url http://localhost:5173
```

Полученный адрес указывается в BotFather (`/newapp` или Menu Button). Проверять стоит
светлую и тёмную тему с переключением на лету, главную кнопку, кнопку «Назад»
и переход на страницу оформления с заполненными полями.

## Подключение к боту

Приложение собирается в статику и выкладывается в корень домена. Адрес в BotFather
менять не нужно, если домен остаётся прежним. Подробности выкатки — в README плагина.
