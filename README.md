# InsurWP — калькулятор медицинской страховки для WordPress

Плагин WordPress, который через шорткод встраивается на любую страницу сайта и считает
стоимость медицинской страховки для иностранцев в Болгарии. Тарифы хранятся в JSON
и редактируются из админ-панели. Основная валюта — евро, опционально цена дублируется в левах.
Кнопка «Заказать» открывает внешнюю страницу оформления и передаёт туда параметры расчёта.

## Что умеет

- Шорткод `[insurwp_calculator]` — вставляется в любую запись, страницу или виджет.
- Сравнение предложений: UNIQA и Bulstrad Life, по Болгарии и по Шенгену, отсортированные по цене.
- Учёт возрастных групп каждого страховщика и ограничений по территории.
- Цены в евро, по галочке — дополнительно в левах по настраиваемому курсу.
- Редактор тарифов (JSON) в админке с проверкой перед сохранением.
- Кнопка «Обновить цены из API» — импорт актуальных тарифов с внешнего сервиса
  с показом изменений «было → стало» и подтверждением.
- Адаптивная вёрстка, светлая и тёмная темы, без Bootstrap и jQuery.

## Стек

- PHP 7.4+, WordPress 5.8+
- REST API WordPress (`/wp-json/insurwp/v1/quote`) для расчёта
- Vanilla JS и CSS без внешних зависимостей
- PHPUnit 9 для юнит-тестов, Node 18+ для сверки тарифов с живым сервисом

## Установка

1. Скопируйте папку `insurwp` в `wp-content/plugins/` на сервере
   (или соберите ZIP и загрузите через «Плагины → Добавить новый → Загрузить плагин»).
2. Активируйте плагин. При активации в базу записываются тарифы по умолчанию
   из `data/prices.default.json` и настройки по умолчанию.
3. Откройте «Страховка» в меню админки и проверьте настройки.
4. Вставьте шорткод на нужную страницу.

Повторная активация не затирает изменённые тарифы и настройки.

## Шорткод

```
[insurwp_calculator]
```

Необязательные атрибуты:

| Атрибут | Значения | Описание |
|---|---|---|
| `title` | текст | Заголовок над формой |
| `order_url` | URL | Своя страница оформления для этого экземпляра |
| `show_bgn` | `yes` / `no` | Показывать ли цену в левах |
| `accent` | `#rrggbb` | Акцентный цвет |
| `territory` | `all` / `bulgaria` / `schengen` | Территория, выбранная по умолчанию |

Пример:

```
[insurwp_calculator title="Страховка для ВНЖ" show_bgn="yes" territory="bulgaria"]
```

На одной странице можно разместить несколько калькуляторов — они не конфликтуют.

## Настройки (админка → «Страховка»)

| Настройка | По умолчанию | Назначение |
|---|---|---|
| Страница оформления | `https://bginfo.eu/insur/` | Куда ведёт кнопка «Заказать» |
| Показывать цену в левах | включено | Дублирование цены в BGN |
| Курс EUR → BGN | `1.95583` | Фиксированная привязка лева к евро |
| Гражданство по умолчанию | `RU` | Код ISO; на форме не спрашивается, на цену не влияет |
| Идентификатор агента | `49` | Поле `agent_id` на стороне сервиса оформления |
| Заголовок калькулятора | «Расчёт стоимости страховки» | Заголовок по умолчанию |
| Акцентный цвет | `#f0ad4e` | Цвет кнопок и выделений |
| Автозапуск расчёта | включено | Запускать расчёт на странице оформления автоматически |
| Примечание о справочном характере | включено | Текст под калькулятором |

## Тарифы

Вкладка «Тарифы» содержит редактор JSON. Формат:

```jsonc
{
  "insurers": {
    "uniqa": {
      "name": "UNIQA",
      "insurance_limit_eur": 30677.51,
      "age_groups": {
        "0_69":  { "min_age": 0,  "max_age": 69 },
        "70_74": { "min_age": 70, "max_age": 74 }
      },
      "prices": [
        { "term": "12 месяцев", "bulgaria_0_69": 89.70, "schengen_0_69": 98.67 }
      ]
    }
  }
}
```

Правила:

- Ключ ячейки собирается как `{территория}_{возрастная_группа}`,
  территории — `bulgaria` и `schengen`.
- **`null` означает «полис не предлагается», а не нулевую цену.** Такие строки
  не попадают в выдачу.
- Возрастные группы задаются либо в `age_groups`, либо в `age_rules`.
  В `age_rules` можно запретить территорию: `"schengen_available": false`
  (так у Bulstrad для группы 65–69).
- Группа без `max_age` (например `70_plus`) означает «и старше».
- Поле `coefficient` у групп справочное — в расчёте не используется, поскольку
  в `prices` уже лежат готовые цены по каждой группе.
- Возраст считается **на дату начала страховки**, а не на текущую дату.

JSON проверяется перед сохранением. Если в нём ошибка, старые тарифы остаются
нетронутыми, а введённый текст возвращается в редактор.

## Подключение внешних сервисов

Плагин работает автономно и **не требует ключей, токенов или регистрации**.
Секретов у него нет, поэтому файл `.env` не используется: все параметры
(адрес страницы оформления, `agent_id`, курс валюты) хранятся в настройках WordPress.

### Сервис тарифов bgmedins.com

Кнопка «Обновить цены из API» обращается к публичному сервису, на котором работает
страница оформления. Авторизация не нужна.

| Эндпоинт | Назначение |
|---|---|
| `https://www.bgmedins.com/system/get_prices.php` | расчёт цен |
| `https://www.bgmedins.com/webservices/getterms.php` | справочник сроков |
| `https://www.bgmedins.com/webservices/getlimits.php` | справочник страховых сумм |
| `https://www.bgmedins.com/webservices/getcountries.php` | справочник стран |

Параметры `get_prices.php`:

| Параметр | Пример | Описание |
|---|---|---|
| `foreigner_country` | `RU` | Код страны ISO |
| `dfb` | `01.07.1990` | Дата рождения, `d.m.Y` |
| `foreigner_term` | `12` | Идентификатор срока (1–12 — месяцы, 13 — 3 дня, 14 — 7 дней, 15 — 15 дней) |
| `foreigner_limit` | `30677.51` | Страховая сумма |
| `date_start` | `06.08.2026` | Дата начала, `d.m.Y` |
| `agent_id` | `49` | Идентификатор агента |
| `jsoncallback` | любое | Ответ приходит в формате JSONP |

Ответ:

```json
{ "status": 0, "Result": [
  { "price": "89.70", "price_eur": "89.70", "price_id": 7436,
    "company_name": "Уника", "logo": "unica.jpg", "shengen": 0, "ipolice": 1 }
] }
```

Плагин опрашивает сервис по 15 срокам и 4 контрольным возрастам (35, 67, 72, 80 лет —
они покрывают все возрастные группы обоих страховщиков), раскладывает ответы по ячейкам
и показывает изменения. Тарифы перезаписываются только после подтверждения.

### Автозаполнение на странице оформления (обязательный шаг)

Кнопка «Заказать» открывает страницу оформления и передаёт параметры в адресной строке:

```
https://bginfo.eu/insur/?ins_type=1&foreigner_limit=30677.51&foreigner_term=12
  &date_start=06.08.2026&dfb=01.07.1990&foreigner_country=RU
  &agent_id=49&insurer=unica&shengen=0&autocalc=1
```

**Сама страница оформления параметры из адреса не читает** — её выпадающие списки
заполняются AJAX-запросами уже после загрузки. Поэтому на неё нужно один раз добавить
сниппет из поставки:

1. Скопируйте `assets/js/bginfo-prefill.js` на сервер страницы оформления
   (например в `/js/bginfo-prefill.js`). Файл можно скачать прямо из админки:
   «Страховка → Подключение».
2. Подключите его перед закрывающим тегом `</body>`:

   ```html
   <script src="/js/bginfo-prefill.js" defer></script>
   ```

Что делает сниппет: дожидается, пока AJAX наполнит списки, проставляет значения из адреса,
при `autocalc=1` нажимает «Рассчитать Стоимость» и подсвечивает выбранное предложение.
Если параметров в адресе нет, скрипт не делает ничего — обычное открытие страницы
работает как раньше.

Без этого шага кнопка «Заказать» всё равно откроет нужную страницу, но поля
придётся заполнить вручную.

## Тестирование

### Юнит-тесты (PHPUnit)

Ядро расчёта не зависит от WordPress, поэтому тесты запускаются обычным PHP.

```bash
composer install
vendor/bin/phpunit
```

Покрыто: возрастные группы обоих страховщиков, границы групп, расчёт возраста
на дату начала полиса, обработка `null`-тарифов, фильтр по территории, пересчёт
в левы, валидация входных данных, маппинг сроков и сборка ссылки «Заказать».

### Смоук-тест серверного пути

Прогоняет активацию, рендер шорткода, REST-эндпоинт, валидацию тарифов и санитизацию
настроек с заглушками функций WordPress. Интернет не нужен.

```bash
php tests/smoke-server.php
```

### Сверка тарифов с живым сервисом

```bash
node tests/verify-prices.mjs      # сверяет data/prices.default.json с bgmedins.com
php tests/smoke-sync.php          # прогоняет тот же импорт, что и кнопка в админке
```

Оба скрипта делают по 60 запросов к внешнему сервису и печатают расхождения.
Если в вашей сборке PHP нет набора корневых сертификатов, укажите его путь:

```bash
INSURWP_CAINFO=/path/to/cacert.pem php tests/smoke-sync.php
```

## Важно о ценах

Тарифы в `data/prices.default.json` — снимок значений, которые внешний сервис
отдавал 1 августа 2026 года. Расчёт носит справочный характер: окончательную
стоимость подтверждает страховщик при оформлении полиса. Перед приёмом оплаты
тарифы следует сверять со страховщиками.
