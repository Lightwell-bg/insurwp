Калькулятор стоимости медицинской страховки для иностранцев в Болгарии. Встраивается шорткодом, тарифы редактируются из админки.

== Description ==

Плагин добавляет шорткод `[insurwp_calculator]`, который выводит форму расчёта стоимости
медицинской страховки для иностранцев в Болгарии и сравнивает предложения страховщиков.

Возможности:

* Форма из пяти полей: тип страховки, страховая сумма, срок, дата начала, дата рождения.
* Сравнение предложений UNIQA и Bulstrad Life по Болгарии и Шенгену, отсортированное по цене.
* Учёт возрастных групп и ограничений каждого страховщика.
* Цены в евро, опционально дублирование в левах по настраиваемому курсу.
* Кнопка «Заказать» открывает страницу оформления и передаёт туда параметры расчёта.
* Тарифы хранятся в JSON и редактируются в админке; есть импорт актуальных цен
  из внешнего сервиса с показом изменений и подтверждением.
* Адаптивная вёрстка, поддержка тёмной темы, без Bootstrap и jQuery.

Плагин не требует ключей API и регистрации.

== Installation ==

1. Скопируйте папку плагина в `wp-content/plugins/` или загрузите ZIP через админку.
2. Активируйте плагин — тарифы по умолчанию запишутся автоматически.
3. Откройте пункт меню «Страховка» и проверьте настройки.
4. Вставьте `[insurwp_calculator]` на нужную страницу.
5. Чтобы поля на странице оформления заполнялись автоматически, подключите на ней
   сниппет `assets/js/bginfo-prefill.js` (инструкция на вкладке «Подключение»).

== Frequently Asked Questions ==

= Можно ли поставить несколько калькуляторов на одну страницу? =

Да, экземпляры не конфликтуют.

= Почему у части сроков нет цены? =

Значение `null` в тарифах означает, что страховщик не предлагает полис на этих
условиях. Это не бесплатная страховка — такие варианты просто не показываются.

= Почему на странице оформления не заполнились поля? =

Эта страница не читает параметры из адреса самостоятельно. Нужно один раз подключить
на ней сниппет `bginfo-prefill.js` — скачать его можно на вкладке «Подключение».

= Откуда берётся курс лева? =

Из настроек, по умолчанию 1.95583 — фиксированная привязка лева к евро.
